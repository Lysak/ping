# PING App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A tiny native Android app that sends real ICMP echo requests to a chosen host, shows a live latency readout plus a BSD-`ping`-style console, and lets the user add and persist custom hosts — no accounts, no trackers, no ads.

**Architecture:** Single-module Jetpack Compose app, one screen, no DI framework, no navigation library. A pure-Kotlin `Pinger` opens an unprivileged `SOCK_DGRAM`/`IPPROTO_ICMP` socket via `android.system.Os`, builds ICMP echo packets itself, and measures RTT with `System.nanoTime()`; it falls back to `exec("ping")` then TCP-connect timing. A `PingViewModel` drives a 1 s loop, keeps cumulative Welford stats and a 60-sample rolling window, and exposes one `StateFlow`. State (custom hosts, selection, theme) is persisted with DataStore Preferences.

**Tech Stack:** Kotlin 2.3.21, Jetpack Compose (BOM 2026.05.01) + Material 3, AGP 9.3.1, Gradle 9.5.0, `androidx.datastore:datastore-preferences`, `androidx.lifecycle` ViewModel, `androidx.core:core-splashscreen`, Spotless + ktlint, GitHub Actions, Dependabot. JUnit4 + `kotlinx-coroutines-test` for unit tests.

**Spec:** `docs/ARCHITECTURE.md` (and `docs/IDEA.md` for intent). Read both before starting. Play/Android compliance: `docs/COMPLIANCE.md`. Privacy policy source: `PRIVACY.md`.

## Global Constraints

- **Language / style:** all code, comments, and committed Markdown in English. Kotlin official style, 4-space indent, 100-column soft limit (`.editorconfig`).
- **License:** GPL-3.0-or-later. Every `.kt` file starts with `// SPDX-License-Identifier: GPL-3.0-or-later`. `LICENSE` is the full GPL-3.0 text. Reused metiq code is credited in `README.md`.
- **Package / applicationId:** `com.lysak.ping`.
- **App label (launcher):** `PING`. Play Store title (listing only, not in code): `Ping — No Ads`.
- **SDK:** `minSdk = 21`, `compileSdk = 36`, `targetSdk = 36`. Never set `maxSdkVersion`.
- **Permissions:** `android.permission.INTERNET` only. No other permission, no `<queries>`, no analytics/crash SDK, no Firebase, no Play Services, no foreground service.
- **Dependencies:** only the list in `docs/ARCHITECTURE.md` § "Full dependency list". Adding any other runtime dependency requires stopping and asking.
- **Edge-to-edge:** `enableEdgeToEdge()` in the Activity; every screen edge respects `WindowInsets` (`statusBars`, `navigationBars`, `ime`). This is a hard requirement — it is the exact regression that broke the reference app on Android 15.
- **Ping defaults:** interval 1000 ms; rolling window 60 samples; cumulative run stats via Welford; TCP fallback probe port 443; per-packet timeout 2000 ms.
- **Default hosts (constants, not deletable, always shown first):** `Google` → `8.8.8.8`, `Cloudflare` → `1.1.1.1`.
- **Commits:** frequent, one per task step group as noted. Do not add any `Co-authored-by` / agent attribution trailer. Do not run `git commit` if the operator's environment forbids it — in that case output the commit message for manual application.

package com.lysak.ping.net

import android.system.Os
import android.system.OsConstants.AF_INET
import android.system.OsConstants.IPPROTO_ICMP
import android.system.OsConstants.SOCK_DGRAM
import org.junit.Assert.assertTrue
import org.junit.Test
import java.io.FileDescriptor

class IcmpSocketSmokeTest {
    @Test
    fun canOpenUnprivilegedIcmpDatagramSocket() {

```kotlin
// SPDX-License-Identifier: GPL-3.0-or-later
package com.lysak.ping.net

object IcmpPacket {

    fun echoRequest(identifier: Int, sequence: Int, payload: ByteArray): ByteArray =
        build(type = 8, identifier = identifier, sequence = sequence, payload = payload, fillChecksum = true)

    fun echoRequestV6(identifier: Int, sequence: Int, payload: ByteArray): ByteArray =
        build(type = 128, identifier = identifier, sequence = sequence, payload = payload, fillChecksum = false)

    private fun build(
        type: Int,
        identifier: Int,
        sequence: Int,
        payload: ByteArray,
        fillChecksum: Boolean,
    ): ByteArray {
        val pkt = ByteArray(8 + payload.size)
        pkt[0] = type.toByte()
        pkt[1] = 0
        pkt[2] = 0
        pkt[3] = 0
        pkt[4] = (identifier ushr 8).toByte()
        pkt[5] = identifier.toByte()
        pkt[6] = (sequence ushr 8).toByte()
        pkt[7] = sequence.toByte()
        payload.copyInto(pkt, destinationOffset = 8)
        if (fillChecksum) {
            val cs = checksum(pkt)
            pkt[2] = (cs ushr 8).toByte()
            pkt[3] = cs.toByte()
        }
        return pkt
    }

    /** RFC 1071 16-bit one's-complement sum. Returns 0 for a packet whose checksum field is already correct. */
    fun checksum(data: ByteArray): Int {
        var sum = 0L
        var i = 0
        while (i + 1 < data.size) {
            sum += ((data[i].toInt() and 0xFF) shl 8) or (data[i + 1].toInt() and 0xFF)
            i += 2
        }
        if (i < data.size) sum += (data[i].toInt() and 0xFF) shl 8
        while (sum shr 16 != 0L) sum = (sum and 0xFFFF) + (sum shr 16)
        return (sum.inv() and 0xFFFF).toInt()
    }

    fun parseEchoReply(datagram: ByteArray, expectedId: Int, expectedSeq: Int): Boolean {
        if (datagram.size < 8) return false
        val type = datagram[0].toInt() and 0xFF
        val code = datagram[1].toInt() and 0xFF
        if ((type != 0 && type != 129) || code != 0) return false
        val id = ((datagram[4].toInt() and 0xFF) shl 8) or (datagram[5].toInt() and 0xFF)
        val seq = ((datagram[6].toInt() and 0xFF) shl 8) or (datagram[7].toInt() and 0xFF)
        return id == (expectedId and 0xFFFF) && seq == (expectedSeq and 0xFFFF)
    }
}

```kotlin
// SPDX-License-Identifier: GPL-3.0-or-later
package com.lysak.ping.net

import kotlin.math.sqrt

data class StatsSnapshot(
    val transmitted: Int,
    val received: Int,
    val lossPct: Double,
    val minMs: Double?,
    val avgMs: Double?,
    val maxMs: Double?,
    val stddevMs: Double?,
)

class PingStats {
    private var n = 0
    private var mean = 0.0
    private var m2 = 0.0
    private var tx = 0
    private var min = Double.MAX_VALUE
    private var max = -Double.MAX_VALUE

    fun recordReply(rttMs: Double) {
        tx++
        n++
        val delta = rttMs - mean
        mean += delta / n
        m2 += delta * (rttMs - mean)
        if (rttMs < min) min = rttMs
        if (rttMs > max) max = rttMs
    }

    fun recordLoss() {
        tx++
    }

    val transmitted: Int get() = tx
    val received: Int get() = n
    val lossPct: Double get() = if (tx == 0) 0.0 else (tx - n) * 100.0 / tx
    val minMs: Double? get() = if (n > 0) min else null
    val avgMs: Double? get() = if (n > 0) mean else null
    val maxMs: Double? get() = if (n > 0) max else null
    val stddevMs: Double? get() = if (n >= 2) sqrt(m2 / n) else null // population, matches BSD ping

    fun snapshot() = StatsSnapshot(transmitted, received, lossPct, minMs, avgMs, maxMs, stddevMs)
}

// SPDX-License-Identifier: GPL-3.0-or-later
package com.lysak.ping.net

object HostValidation {
    private val LABEL = Regex("^(?!-)[A-Za-z0-9-]{1,63}(?<!-)$")
    private val IPV4 = Regex("^((25[0-5]|2[0-4]\\d|1?\\d?\\d)\\.){3}(25[0-5]|2[0-4]\\d|1?\\d?\\d)$")

    fun isValid(host: String): Boolean {
        if (host.isBlank() || host != host.trim() || host.any { it.isWhitespace() }) return false
        if (host.length > 253) return false
        if (IPV4.matches(host)) return true
        if (host.contains(':')) return runCatching { java.net.InetAddress.getByName("[$host]") }.isSuccess &&
            host.all { it == ':' || it.isLetterOrDigit() }
        val labels = host.split('.')
        return labels.isNotEmpty() && labels.all { LABEL.matches(it) }
    }
}

`Pinger.kt`:
```kotlin
// SPDX-License-Identifier: GPL-3.0-or-later
package com.lysak.ping.net

import android.system.Os
import android.system.OsConstants
import android.system.StructPollfd
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.io.FileDescriptor
import java.net.Inet6Address
import java.net.InetAddress
import java.net.InetSocketAddress
import java.net.Socket
import java.net.UnknownHostException

private val TIME_RE = Regex("""time[=<]([0-9]+(?:\.[0-9]+)?)\s*ms""")
private val TTL_RE = Regex("""ttl=([0-9]+)""", RegexOption.IGNORE_CASE)

internal fun parseExecPingLine(line: String): Pair<Double, Int?>? {
    val t = TIME_RE.find(line)?.groupValues?.get(1)?.toDoubleOrNull() ?: return null
    val ttl = TTL_RE.find(line)?.groupValues?.get(1)?.toIntOrNull()
    return t to ttl
}

class Pinger {

    suspend fun probe(host: String, seq: Int, timeoutMs: Int = 2000): PingSample =
        withContext(Dispatchers.IO) {
            val addr = try {
                InetAddress.getByName(host)
            } catch (_: UnknownHostException) {
                return@withContext PingSample.Lost(seq, LossReason.UNRESOLVED)
            }
            datagramProbe(addr, seq, timeoutMs)
                ?: execProbe(host, seq, timeoutMs)
                ?: tcpProbe(addr, seq, timeoutMs)
        }

    private fun datagramProbe(addr: InetAddress, seq: Int, timeoutMs: Int): PingSample? {
        val v6 = addr is Inet6Address
        val fd: FileDescriptor = try {
            Os.socket(
                if (v6) OsConstants.AF_INET6 else OsConstants.AF_INET,
                OsConstants.SOCK_DGRAM,
                if (v6) OsConstants.IPPROTO_ICMPV6 else OsConstants.IPPROTO_ICMP,
            )
        } catch (_: Throwable) {
            return null // fall through to exec
        }
        try {
            Os.connect(fd, addr, 0)
            val localPort = (Os.getsockname(fd) as InetSocketAddress).port
            val id = localPort and 0xFFFF
            val payload = ByteArray(16) { it.toByte() }
            val packet = if (v6) IcmpPacket.echoRequestV6(id, seq, payload)
            else IcmpPacket.echoRequest(id, seq, payload)

            val start = System.nanoTime()
            Os.write(fd, java.nio.ByteBuffer.wrap(packet))

            val pfd = StructPollfd().apply {
                this.fd = fd
                events = OsConstants.POLLIN.toShort()
            }
            val ready = Os.poll(arrayOf(pfd), timeoutMs)
            if (ready == 0) return PingSample.Lost(seq, LossReason.TIMEOUT)

            val buf = java.nio.ByteBuffer.allocate(1500)
            val n = Os.read(fd, buf)
            val data = ByteArray(n).also { buf.flip(); buf.get(it) }
            val rttMs = (System.nanoTime() - start) / 1_000_000.0

            return if (IcmpPacket.parseEchoReply(data, id, seq)) {
                PingSample.Reply(seq, rttMs, ttl = readTtl(fd), via = Method.ICMP, bytes = payload.size)
            } else {
                PingSample.Lost(seq, LossReason.ERROR) // unmatched — let caller's next probe decide
            }
        } catch (_: Throwable) {
            return null
        } finally {
            runCatching { Os.close(fd) }
        }
    }

    /** TTL/hop-limit of the reply, API 33+ only (needs Os.recvmsg + IP_RECVTTL). */
    private fun readTtl(fd: FileDescriptor): Int? = null // TODO(api33): wire IP_RECVTTL when minSdk allows

    private fun execProbe(host: String, seq: Int, timeoutMs: Int): PingSample? {
        return try {
            val secs = (timeoutMs / 1000).coerceAtLeast(1)
            val p = ProcessBuilder("ping", "-n", "-c", "1", "-W", secs.toString(), host)
                .redirectErrorStream(true).start()
            val out = p.inputStream.bufferedReader().readText()
            p.waitFor()
            val hit = out.lineSequence().firstNotNullOfOrNull { parseExecPingLine(it) }
                ?: return if (out.contains("100% packet loss")) PingSample.Lost(seq, LossReason.TIMEOUT) else null
            PingSample.Reply(seq, hit.first, hit.second, Method.ICMP_EXEC, bytes = 56)
        } catch (_: Throwable) {
            null
        }
    }

    private fun tcpProbe(addr: InetAddress, seq: Int, timeoutMs: Int): PingSample {
        return try {
            val start = System.nanoTime()
            Socket().use { it.connect(InetSocketAddress(addr, 443), timeoutMs) }
            PingSample.Reply(seq, (System.nanoTime() - start) / 1_000_000.0, null, Method.TCP, bytes = 0)
        } catch (_: java.net.SocketTimeoutException) {
            PingSample.Lost(seq, LossReason.TIMEOUT)
        } catch (_: Throwable) {
            PingSample.Lost(seq, LossReason.UNREACHABLE)
        }
    }
}
```
Note: `datagramProbe` returning `PingSample.Lost(seq, TIMEOUT)` is a real result and short-circuits (Kotlin `?:` only falls through on `null`). Returning `null` means "this method is unavailable, try the next". An unmatched reply returns `Lost(ERROR)` — acceptable; a stricter loop-and-drain is out of scope (`// ponytail: single read; drain-until-match if stray replies ever cause fld loss`).

        assertEquals(listOf("8.8.8.8", "1.1.1.1"), p.hosts.map { it.value })
        assertEquals("8.8.8.8", p.selected.value)
    }

        assertTrue(p.hosts.last().deletable)

        val r = repo()
        assertFalse(r.addHost("bad", "not a host"))
        assertFalse(r.addHost("dup", "8.8.8.8"))
